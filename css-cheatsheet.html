fr unit & functions

Grid Functions

/* fr = fractional unit */
grid-template-columns: 1fr 2fr 1fr;
/* 25% 50% 25% of available space */

/* minmax() */
grid-template-columns:
  minmax(100px, 1fr);
/* at least 100px, up to 1fr */

/* repeat() */
grid-template-columns:
  repeat(4, 1fr);

/* auto-fill vs auto-fit */
/* auto-fill: keeps empty tracks */
/* auto-fit: collapses empty tracks */
grid-template-columns:
  repeat(auto-fit,
    minmax(250px, 1fr));

Positioning & Z-index

position values

CSS Position

ValueBehavior
staticDefault — in normal flow, top/left/etc. ignored
relativeNormal flow + offset from self; creates stacking context
absoluteRemoved from flow; offset from nearest positioned ancestor
fixedRemoved from flow; offset from viewport; ignores scroll
stickyNormal flow until scroll threshold, then fixed
/* Absolute centered overlay */
.overlay {
  position: absolute;
  inset: 0; /* top:0 right:0 bottom:0 left:0 */
}

/* Centered absolutely */
.centered {
  position: absolute;
  top: 50%; left: 50%;
  transform: translate(-50%, -50%);
}

/* Sticky header */
header {
  position: sticky;
  top: 0; z-index: 100;
}
stacking

Z-index & Stacking Context

/* Z-index only works on positioned elements */
.modal     { z-index: 1000; position: fixed; }
.dropdown  { z-index: 100; position: absolute; }
.tooltip   { z-index: 50;  position: relative; }

/* New stacking context created by: */
/* position: relative/abs/fixed/sticky + z-index */
/* opacity < 1 */
/* transform, filter, will-change */
/* isolation: isolate (explicit!) */

/* Fix z-index wars */
.component {
  isolation: isolate; /* own stacking ctx */
}

/* Z-index scale convention */
/* base: 0, sticky: 100 */
/* dropdown: 200, modal: 300 */
/* toast: 400, tooltip: 500 */

CSS Animations

@keyframes

Keyframe Animations

/* Define animation */
@keyframes slideIn {
  from {
    transform: translateX(-100%);
    opacity: 0;
  }
  to {
    transform: translateX(0);
    opacity: 1;
  }
}

@keyframes pulse {
  0%, 100% { transform: scale(1); }
  50%      { transform: scale(1.1); }
}

/* Apply animation */
.card {
  /* name duration timing delay */
  /* iteration direction fill-mode */
  animation:
    slideIn 0.5s ease-out 0s
    1 normal both;

  /* Or separate properties: */
  animation-name: slideIn;
  animation-duration: 0.5s;
  animation-timing-function: ease-out;
  animation-delay: 0.1s;
  animation-iteration-count: infinite;
  animation-direction: alternate;
  animation-fill-mode: forwards;
  animation-play-state: paused;
}
performance

Animation Best Practices

/* GPU-accelerated properties (no reflow) */
/* ✓ Use these: */
transform: translate(), scale(), rotate();
opacity: 0 to 1;
filter: blur(), drop-shadow();

/* ✗ Avoid animating (causes reflow): */
/* width, height, top, left, margin,  */
/* padding, font-size, display         */

/* Hint browser to create layer */
.animated {
  will-change: transform, opacity;
  /* Remove after animation done! */
}

/* Staggered animations */
.item:nth-child(1) { animation-delay: 0.1s; }
.item:nth-child(2) { animation-delay: 0.2s; }
.item:nth-child(3) { animation-delay: 0.3s; }

/* Respect motion preferences */
@media (prefers-reduced-motion: reduce) {
  * { animation-duration: 0.01ms !important; }
}
